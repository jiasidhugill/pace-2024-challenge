# Change the PACE

Change the PACE is an educational game designed with data from NASA's newest satellite mission, PACE (Plankton, Aerosol, Cloud, and ocean Ecosystem). Using NetCDF Python libraries, GIS data analysis, and React and Flask web frameworks, we created this project for the 2024 NASA Space Apps Challenge.

Play the game [here](https://change-the-pace.vercel.app/).
